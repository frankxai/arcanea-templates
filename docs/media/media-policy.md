# Template Media Policy

Templates ship only redistributable, clearly licensed demo assets. Use stable asset IDs and immutable approved renditions. Never ship private masters, user data, embedded credentials, unverifiable partner marks or generated factual UI. Screenshots must match the released version and label mock data.

A Vercel-hosted child uses Vercel Blob/Image for new web media unless a documented exception exists. Every media-heavy template includes performance budgets, alt text/captions, reduced-motion behavior, user-controlled audio and a static fallback.
