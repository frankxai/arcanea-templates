# Arcanea Templates

A governed catalog of Arcanea web, agent and creative templates. Each child repository carries its own license, release evidence and maintenance owner.

## Current verified catalog state

| Template | Repository state | Catalog state |
|---|---|---|
| Cosmic Landing | archived | retired from active catalog |
| Arcanea Chat | archived | retired from active catalog |
| Arcanea Dashboard | active | audit required before marketplace claim |
| Arcanea MCP Starter | active | audit required before marketplace claim |

catalog.yaml is the machine-readable source. Archived repositories remain useful evidence but are not advertised as maintained products. An active repository is not automatically a release-ready template.

## Release-ready definition

A template becomes release-ready only when it has a clean clone/install/build, public license, zero-secret demo path, responsive/accessibility and reduced-motion review, real screenshots, product and listing manifests, customization guide, example outcome, dependency/update policy, verified preview, rollback and named maintenance owner.

## Product direction

The catalog may include free open templates and clearly separated commercial extensions. Near-term candidates are a cinematic experience starter, world-engine starter and publishing template. They reuse the shared design/media/commerce rails and are created only in a canonical repository selected through portfolio review.

## Distribution

GitHub and Vercel Templates fit open deployable starters. Framer and Webflow require native, tool-specific products rather than automated conversion claims. Creative Market fits editable design assets. Every submission derives from one listing manifest and requires direct verification.

See MARKETPLACE.md and docs/media/media-policy.md.

## Agent operating guidance

Repository agents use the shared Starlight operating contract in `AGENTS.md` alongside local instructions.
The contract asks agents to establish a useful outcome, select relevant skills, complete authorized work,
verify current sources, refine the actual artifact, and report evidence and remaining gates.
It covers human agency, privacy, rights, resource stewardship and bounded proactivity.
Repository identity, brand, canon, build commands and release gates remain local.

[Pinned contract](https://github.com/frankxai/Starlight-Intelligence-System/blob/794db1e51a55a128816f7aa266eb0ac1dbd452c3/docs/architecture/agents-md/band-a.md)
· [Projection and verification](https://github.com/frankxai/Starlight-Intelligence-System/blob/794db1e51a55a128816f7aa266eb0ac1dbd452c3/docs/architecture/AGENTS-MD-CONTRACT.md)

These files supply operating guidance. They do not activate an agent, grant tool permissions,
schedule recurring work, certify compliance or prove a live capability.
